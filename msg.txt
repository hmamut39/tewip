Phase 50: Vue, Svelte and Angular - the frameworks never run

access had been measured on React, Razor and Nunjucks. Vue, Svelte and
Angular had been supported since Phases 28 and 37 and never pointed at
anything. immich (SvelteKit), nocodb (Vue) and angular/components - Angular
Material, the Angular team's own library, with a dedicated accessibility
focus and therefore the Angular equivalent of GOV.UK.

Angular Material reported 533 barriers, 426 of them unlabelled inputs, in an
accessibility library. Every one was <mat-form-field><mat-label>Title
</mat-label><input matInput></mat-form-field>, where MatFormField binds the
two when it renders. The label is real and simply not expressed in the file.
This is the third spelling of the same family: PatternFly named the control
in a prop, ASP.NET bound it through the model with asp-for, Angular Material
wraps the two together. A custom element containing a label now means
"cannot say"; an ordinary <my-card> around a bare input is still a barrier.

And Angular's events were invisible. click-without-keyboard read four exact
attribute names and Angular binds events as (click). angular/components has
414 of them and Tewip saw none, so the rule could never fire in any Angular
project at all - the library reported zero, which looked like a clean result
and was blindness. Vue's modifier forms were missed for the same reason: the
attribute is @click.stop, not @click, and nocodb has 455 of those. Svelte
needed nothing, which is why this only surfaced on a third framework.

A zero is the hardest wrong answer to notice, because it looks like the
answer you wanted.

The new detection needed its own restraint: <mat-checkbox (click)> is a
checkbox with full keyboard handling once Angular renders it, and
t.component does not catch a name spelled with a dash. A <tr (click)> beside
it is still a barrier, because table rows really are not focusable.

Angular 194 barriers, nocodb 481, immich 25, samples of all three read
against their source. GOV.UK stayed at 6, which is the regression check that
matters most here.

Eleven projects, eighteen checks. 986 tests.
